## 每题怎么用

读题与样例 → 自己概括“输入、保存什么、如何更新、输出” → 看三条提醒 → 在空白代码单元编写 → 检查边界。不要背整题答案；要能在空白文件里重写关键动作。

每题包含原题来源、题意整理、样例、三条初步提醒、样例数据代码单元、空白作答单元和自查项。没有完整题解、算法答案、自动判题结果或虚构的练习成绩。

## 在 VSCode / Jupyter 中练习

打开对应的 `notes.ipynb`，选择可用的 Python 3 内核，先运行样例数据单元，再写代码。运行 Notebook 需要 VSCode 的 Jupyter 支持与可用内核；环境未就绪时先阅读题目，不要把今晚耗在环境配置上。

本地练习可以从 `sample_input.splitlines()` 取得每行数据，不必在 Notebook 弹窗中逐行输入。HJ20 原站需要读到 EOF，因此尤其适合先用多行样例练习。LC3 提供的是字符串参数 `s`。

这些输入字符串只是练习素材，`expected_output` / `expected_result` 只是比对值，不会自动判断代码是否正确。代码完成后，再写成 `.py`，替换为题目要求的标准输入输出；只提交自己的作答代码，不提交样例数据和 Notebook 辅助内容。

## 两个题面细节

- **HJ17**：当前题面要求距离在 1～99，一到两位数字；小于 10 可以有一个前导零。0、超过两位数字、非法方向要忽略。[原题](https://www.nowcoder.com/practice/119bcca3befb405fbe58abe9c532eb29)
- **HJ20**：当前页面要求至少 8 位；禁用的是两个互不重叠、长度至少为 3 的相同子串。重叠重复不单独判失败，输入也没有组数行。[原题](https://www.nowcoder.com/practice/184edec193864f0985ad2684fbc86841)
