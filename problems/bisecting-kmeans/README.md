# 二分 K-Means（Bisecting K-Means）

## 题目概述

反复使用 2-means 拆分一个已有簇，直到达到目标簇数量。每轮选择 SSE 降幅最大的候选拆分，并在拆分完成后输出所有簇的大小。

## 输入与输出

输入：

1. 目标簇数量 `N`。
2. 二维点的数量 `L`。
3. 接下来 `L` 行，每行包含浮点坐标 `x y`。

输出：每次拆分后，将当前所有簇的大小按降序输出在一行中。

## 约束

原始源文件没有保留完整题目约束。当前实现假设输入点集非空、`1 <= N <= L`，并且每次 2-means 拆分都能产生两个非空子簇。

## 算法

1. 初始时将所有点放在同一个簇中。
2. 对每个可拆分簇运行确定性的 2-means，并以 x 坐标最小和最大的点初始化两个中心。
3. 计算 `split_gain = parent_sse - child_1_sse - child_2_sse`。
4. 选择 gain 最大的候选。如果多个 gain 在容差范围内相同，则优先选择点数更多的父簇；仍然相同时保留遍历顺序中更早的簇。
5. 用两个子簇替换被选中的父簇，然后继续下一轮。

## 复杂度

设目标簇数量为 `K`、点数为 `L`、每次 2-means 最多迭代 `I = 1000` 次。考虑重复的 SSE 扫描，完整候选评估过程的时间复杂度约为 `O(K * I * L)`；保存点引用所需的辅助空间为 `O(L + K)`。

## 关键模式

- 欧氏距离平方与质心计算
- 使用 SSE 作为聚类目标
- 带收敛检查的 Assignment / Update 迭代
- Split Gain 比较与确定性 tie-breaking
- 标准输入解析与仅保留提交所需输出
